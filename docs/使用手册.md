# ROG 资源管理器主题 · 使用手册

**版本 1.1.0 ｜ 适用 Windows 11（24H2 / 25H2 / 26H2，build 26100 及以上）｜ 引擎无需管理员权限**

---

## 一、这是什么

把 Windows 资源管理器（explorer.exe）变成「红黑 RO姬」风格的一套美化组件：

| 效果 | 说明 |
|---|---|
| **ROG 刀锋边框** | 窗口外沿的加厚金属边框：机加工细纹底 + 长短交替的刃形切面 + 四角高光切角。不是一圈发光条纹，而是分层明暗的金属刃口质感 |
| **系统按钮** | 默认**使用系统原生三按钮**（不重绘）。想要自定义：设置 → 按钮，可只重绘关闭键或三颗全接管（黑底白符号，关闭键悬停红底黑叉） |
| **顶部铭牌** | 左上角：AsusRog-Regular 字体写的 **REPUBLIC OF GAMERS**；右上角：**红色 ROG 之眼 logo**（矢量绘制，都在窗口上方的边框条带内） |
| **glitch 故障特效** | 边框会**随机**出现短暂的故障效果（水平切片错位 + 红青错色 + 扫描亮条）；可选**作用范围**（仅边框 / 边框+内部 / 仅内部）、强度、色差宽度、条纹宽度、间隔与时长，随时可关 |
| **ROG 之眼图标** | 程序、托盘、任务栏用的都是败家之眼矢量图标（16-256 全尺寸） |
| **拖动跟手** | 拖动/缩放窗口时边框**实时跟随**（拖动中走简化帧，停手后立刻补回满画质） |
| **多虚拟桌面** | 切到别的虚拟桌面时，前一个桌面的窗口边框会自动隐藏，不会「飘」到当前桌面上 |
| **图形设置界面** | 右键任务栏托盘图标 → **设置…**（或双击 **设置.bat**）：背景壁纸、边框花纹、铭牌、按钮、配色、高级，六大分类，改完即时生效 |
| **可切换的背景壁纸** | 三张 ROG / RO姬 壁纸任选其一，**真正垫在文件列表背景里**（文件名始终可读）；等比铺满、改窗口大小只改变露出范围、不拉伸 |
| **红黑主题层** | 深色模式 + ROG 红强调色（窗口边框、任务栏随主题变红） |
| **托盘控制** | 暂停 / 继续、重载配置、打开配置、退出 |

> **桌面壁纸不受影响**：本主题只针对资源管理器界面，安装与卸载都**不会**修改你的桌面壁纸。

## 二、安装

1. 双击 **安装.bat**（安装引擎并启动，无需管理员）。
2. 需要背景壁纸时，双击 **资源管理器背景.bat**（会弹管理员授权），选择 1 / 2 / 3 即可。
3. 卸载：双击 **卸载.bat**，或在「设置 → 应用」里卸载。

安装脚本只做**用户级**改动：

| 位置 | 内容 | 卸载时 |
|---|---|---|
| %LOCALAPPDATA%\RogHimeTheme\ | 程序、素材、配置 | 删除 |
| ...\Themes\Personalize | 深色模式、透明效果、强调色开关 | 还原 |
| ...\Windows\DWM | 强调色 = #FF0029、ColorPrevalence=1 | 还原 |
| HKCU\...\Run\RogHimeTheme | 开机自启 | 移除 |
| HKCU\...\Uninstall\RogHimeTheme | 应用列表登记 | 移除 |

可选参数：

    powershell -ExecutionPolicy Bypass -File install.ps1 -NoAutostart

## 三、原理（为什么它几乎不可能拖垮资源管理器）

市面上大多数资源管理器美化工具（ExplorerBlurMica、ExplorerPatcher 等）需要把 DLL 注入 explorer.exe，
一旦 hook 出错就是「桌面 + 任务栏一起崩」。本主题的**边框与按钮**采用**零注入**方案：

1. 用 DWM 官方接口 DwmSetWindowAttribute 给资源管理器窗口设置标题栏配色；
2. 在窗口**正上方**叠加一个「鼠标穿透」的分层窗口（WS_EX_LAYERED + WS_EX_TRANSPARENT），画出边框、铭牌与三颗按钮。

所有点击都穿透到**原生按钮**上，所以按钮功能、Snap Layouts、Aero Snap、双击标题栏、标签页拖拽全部保持原生；
覆盖层崩溃也不影响资源管理器，最多是美化消失，重开引擎即可。

> 唯一取舍：关闭按钮的视觉由我们绘制（原生按钮仍在其下工作），因此它的悬停高亮是我们自己的样式。

**背景壁纸**是唯一需要注入的部分，通过开源项目 Windhawk 的 mod 实现（见第五节），
由 Windhawk 自己管理注入与卸载，可随时关闭。

## 五、资源管理器背景壁纸（可切换）

资源管理器的文件列表背景由系统自己绘制，外部窗口盖上去只会挡住文件、把画面压暗。
本主题采用 **ExplorerBgTool**（作者 Maplespe，MIT 许可）的**外壳扩展**方式，
由资源管理器自己调用它来绘制背景 —— 图片真正垫在文件**下面**，文件名与图标始终清晰可读。

**使用方法**

1. 双击 **资源管理器背景.bat**（会弹一次管理员授权，因为要注册外壳扩展）。
2. 菜单里选 1 / 2 / 3 切换壁纸，选 0 关闭并完全反注册。
3. **切换壁纸立即生效**：重开一个资源管理器窗口即可（不用重启资源管理器、更不用重启系统）。
   只有「首次启用」和「关闭」需要重启一次资源管理器来加载/卸载组件。

三张壁纸位于 %LOCALAPPDATA%\RogHimeTheme\assets\wallpapers\bg1.jpg ~ bg3.jpg，
可直接替换成自己的图片（保持文件名即可）。

**显示方式**（默认等比铺满，图片永不变形；窗口变大只露出更多内容，不会拉伸）：

    # 0=左上 1=右上 2=左下 3=右下 4=居中 5=缩放 6=缩放并填充（默认）
    # Alpha = 不透明度 0-255，想淡一点可以调小
    powershell -File tools\set-explorer-background.ps1 -Index 1 -PosType 6 -Alpha 255
    powershell -File tools\set-explorer-background.ps1 -Index 2 -PosType 3 -Alpha 200

* 想给某个文件夹单独设图、或改成乱序随机：编辑
  %LOCALAPPDATA%\RogHimeTheme\ExplorerBg\config.ini（写法见该文件内注释，支持 CLSID 路径）。
* 若图片损坏导致资源管理器崩溃：按住 **ESC** 再打开资源管理器（这样不加载图片），
  然后运行 资源管理器背景.bat 选 0 关闭。
* 不需要背景时选 0 即可完全反注册；卸载主题时也会自动反注册。

## 六、图形设置界面

右键任务栏托盘里的**红色眼睛图标 → 设置…**（也可双击 **设置.bat**）。
界面是**深色主题**（黑底 / 白字 / 红字标题），**滑轨是自绘的红色轨道 + 红色滑块**，**页签条为深红底、选中页签亮红底白字**；下拉框与文本框也都是自绘的，不会出现系统那圈白色边框。共六页：

| 页签 | 内容 |
|---|---|
| **背景** | 「**背景选择**」下拉框：不使用 / 内置壁纸 1-3 / **自定义图片…**（选中会弹出文件浏览）；「显示方式」下拉框：居中 / 缩放 / **缩放并填充**（默认）；**背景遮罩**与**不透明度**滑轨；右侧实时预览 |
| **边框** | 厚度、顶部条带、切角、圆角、风格（下拉）、刃片间距与宽度、亮刃间隔、机加工纹路、发光强度、标题栏装饰线、最大化隐藏（以上数值全部是**滑轨**）；以及 **glitch 动态特效**（见下） |
| **铭牌** | 铭牌开关、文字内容、下划线、右上角 ROG 之眼开关与大小 |
| **按钮** | 接管范围（默认「不显示」= 系统原生三按钮）、关闭键悬停变红、面板描边开关、尺寸与位移微调、圆角 |
| **配色** | 17 项颜色，点色块直接调色盘 |
| **高级** | 对所有窗口生效、DWM 材质、**强制系统强调色**（关掉会自动还原你原来的颜色）、强调色、轮询间隔、三个快捷入口 |

### glitch 动态特效（边框页）

| 控件 | 范围 | 说明 |
|---|---|---|
| 启用随机故障特效 | 开/关 | 总开关，关掉完全不触发 |
| 立即试一次 | 按钮 | 立刻触发一次，方便边调边看 |
| 作用范围 | 仅边框 / 边框+内部 / 仅内部 | 默认仅边框 |
| 故障强度 | 滑轨 **0~100** | 越大切片越多、错位越大 |
| 色差宽度 | 滑轨 **0~200 px** | 红青错位量，0 = 无色差 |
| 故障条纹宽度 | 滑轨 **1~80 px** | 切片与扫描条的粗细 |
| 最短间隔 | 滑轨 **0~600 s** | 上一次结束后到下一次的等待，**0 = 连续故障**（仍按单次持续时间分段） |
| 最长间隔 | 滑轨 **0~600 s** | 与最短**自动联动**，永远保证「最短 ≤ 最长」 |
| 单次持续时间 | 滑轨 **120~5000 ms** | 低于 120ms 基本看不见 |

* 每条滑轨的**标题里直接写着当前值**（形如「边框厚度 (2~40) = 9」），拖动时实时刷新；右侧还有红色大字显示。
* 时间参数在界面和程序里**双重钳制**，不可能出现「最短 > 最长」这类自相矛盾的值。
* 故障对所有**可见**的资源管理器窗口同时生效（不需要窗口在前台）。

### 背景系统（两套机制，程序自动切换）

| 条件 | 用哪套 | 能管什么 |
|---|---|---|
| 装了 Windhawk + **Windows 11 File Explorer Styler** mod | **XAML 方案**（推荐） | 文件列表 **+ 主文件夹** |
| 没装 | 回退 ExplorerBgTool（外壳扩展） | 只有文件列表 |

**XAML 方案**通过写 Windhawk mod 的设置实现（注册表 `HKLM\SOFTWARE\Windhawk\Engine\Mods\windows-11-file-explorer-styler\Settings`）：

```
controlStyles[0] → Grid#DetailsViewControlRootGrid   文件列表
controlStyles[1] → Grid#HomeViewRootGrid             主文件夹
```

* 保存时会**弹一次 UAC 提权**（设置存在 HKLM），必须点「是」
* 支持热重载，**改完不用重启资源管理器**
* 启用 XAML 时程序会**自动把外壳扩展那层设成全透明**，避免两层同时画

**主文件夹可调参数**（背景页）：

| 控件 | 范围 | 说明 |
|---|---|---|
| 主文件夹使用不同背景 | 勾选 | 关掉则跟随通用背景 |
| 图片选择 | 1 / 2 / 3 / 跟随通用 | |
| 主文件夹图片不透明度 | 滑轨 0~100% | **等效遮罩/压暗**：越低，底下深色主题越透出来，文字越清楚 |
| 主文件夹缩放方式 | 填充 / 完整 / 拉伸 / 原始 | |
| 主文件夹对齐方式 | 居中 / 左 / 右 / 顶 / 底 | |

> **为什么没有独立遮罩层**：Windhawk 的样式系统只能设置 XAML 属性（`属性:=<值>`），无法插入新的覆盖层。
> 用 `Opacity` 配合深色窗口背景可达到同样压暗效果，而且不会色偏。

### 强调色（关系到「一般窗口」）

「高级 → 强制把系统强调色改成 RO姬红」默认开启（默认色为暗红 **#800002 / RGB 128,0,2**），它会把 Windows 的系统强调色改成 RO姬红，
所以你**所有普通窗口**的标题栏高亮、开关、选中框都会变成红色。

**不喜欢就取消这个勾**，程序会自动把你原来的系统颜色**还原**回去（首次接管时会自动备份原值）。

## 七、常见问题

**Q：装了没反应？**
1. 托盘有没有红色眼睛图标？没有就运行 %LOCALAPPDATA%\RogHimeTheme\RogHimeEngine.exe；
2. 打开一个资源管理器窗口，等 1 秒；
3. 如果窗口被拖到屏幕外，边框也会跟着跑到屏幕外——运行 **修复窗口位置.bat** 把窗口拉回来。

**Q：铭牌会不会挡住「主文件夹」标签页？**
不会。铭牌画在窗口**上方的边框条带里**（窗口矩形之外），且标题栏装饰线默认关闭。
如果手动把 CaptionDecor 打开，那条线会画在标题栏底部，可能与标签行重叠，建议保持 0。

**Q：会不会变卡？**
覆盖层只在窗口移动/缩放/悬停时重绘；拖动窗口时先隐藏、停下后再画。
想更省可以设 AllWindows=0、PollMs=150，或用托盘菜单「暂停美化」。

**Q：杀毒软件报警？**
边框部分不做注入、不做 hook、不写系统目录。背景壁纸部分是一个**外壳扩展**（资源管理器自己加载它，不是我们注入资源管理器），
若杀毒软件提示注册表写入，选择允许即可；不需要背景时选 0 会把它彻底反注册。

**Q：怎么彻底还原？**
双击 卸载.bat。它会先反注册背景外壳扩展、重启一次资源管理器释放 DLL，再删除全部文件。

## 九、技术备注

* **边框几何**：DwmGetWindowAttribute(hwnd, DWMWA_CAPTION_BUTTON_BOUNDS) 取三颗系统按钮外接矩形（窗口相对坐标），
  三等分得到每颗按钮位置；取不到时回退到 SM_CXSIZE / SM_CYSIZE / SM_CYCAPTION 经验公式。
* **刃形花纹**：斜率取 ROG «///» 官方比例 0.4（dx/dy = 4/10），长短与明暗交替形成「一排刀刃」的节奏；
  底色用 135° 渐变做金属厚度，四角另加 45° 切角高光。
* **铭牌排版**：用 GraphicsPath.AddString 取文字真实墨迹包围盒排版，避免 Calligraphr 字体字宽异常导致间距错乱。
* **Z 序**：覆盖层用 SetWindowPos 插到目标窗口正上方（GW_HWNDPREV），别的窗口盖住资源管理器时边框也会一起被盖住。
* **进程**：引擎是独立进程，不加载任何第三方模块进 explorer.exe。
