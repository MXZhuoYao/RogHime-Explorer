# 变更日志

## v2.2.0

### 新增
- 双主题系统：RO姬（红黑）/ 吹雪（白蓝），支持跟随系统浅色/深色自动切换
- 碳纤维材质边框，按主题自动切换红/蓝版本
- 边框与窗口的上下 / 左右留白独立可调
- 开机自启四种方式（注册表 / 启动文件夹 / 计划任务 / 关闭），设置界面与托盘均可切换
- 单文件安装向导（默认管理员 · 可自选安装位置 · 5 页分页界面）
- 设置界面「关于」页新增卸载按钮

### 改进
- 角落包围线与边线统一颜色，浅色主题下改用蓝色（原白色不可见）
- 浅色主题刃片的第三种配色由近黑色改为浅蓝灰
- 移除雪花装饰与角落短线
- 所有滑轨改为按标签实际宽度定位，不再遮挡文字

### 修复
- 安装时不再无条件修改系统强调色（改为可选，默认关闭）
- 安装脚本读取配置的壁纸索引，首次打开即为正确壁纸
- 安装流程先注册扩展再生成带遮罩的图片，顺序修正
- 主题切换不再覆盖用户选择的边框风格
- 材质缓存按路径分别缓存，星辰/碳纤维不再互相覆盖
- 背景或遮罩变化也会触发 Explorer 刷新
- 打包流程加入主程序、配置文件、脚本语法等十项自动校验

## v2.1.0

- 自定义标题栏与深色设置界面
